# Cinematic art and motion

September 23, 2026. Environment art was created with the built-in ImageGen tool and encoded as WebP for the game. No image-generation API, account or paid service is used by the running application. Original generated PNGs remain in the local ImageGen output folder; the game uses the six files in `public/assets/`.

The presentation is layered 2D environment art with animated lighting, mist, dust, reflective water, photographic machinery, time anchors and portal effects. It does not use a real-time 3D engine. The past garden has a separate maintained, sunlit environment and young tree; the future has weathered architecture and an ancient tree. The bridge and flooded variants preserve the camera composition.

Images retain their generated 1672 × 941 dimensions, encoded at WebP quality 87. The complete asset set is approximately 2.6 MB. Styles and compositing live in `public/cinematic.css` and `public/scenes.js`. `updateScene` keeps the environment mounted while game state changes; chat messages do not restart the ambient animation. All continuous motion and transitions respect `prefers-reduced-motion`. Paused rooms freeze ambient motion.
